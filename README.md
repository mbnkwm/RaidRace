# Raid Race

This is a Fabric mod for Minecraft 1.21.11, created for events at Wynn Analytics to collect data on what rewards 
players get from raids and from how many pulls. 

### How to use

Download the mod from [the releases section](https://github.com/mbnkwm/RaidRace/releases/latest), install it like you 
would any other mod and then start completing raids, once you've opened the reward chest there should be a message 
in-game telling you that the data was collected. 

**If you do not see the message after opening a reward chest or you see an error please report it either here or in the 
discord.** If the message is annoying you then you can toggle it with `/raidrace silent`.

If you'd like to see your progress along the way you can use the command `/raidrace pulls` and it'll tell you how
many pulls you've collected this session and how many overall.

You can also check how much time is left in/until the event with `/raidrace time`.

Once the event is complete there'll be a channel to submit your data in the discord server, you can use the command
`/raidrace file` to open the folder where the data is stored and then send that file into the channel.
